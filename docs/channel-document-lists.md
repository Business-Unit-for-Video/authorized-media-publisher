# 频道视频与转写文档目录

视频标题、来源和转写进度来自两个公开转写仓库。CSV 是原视频发布队列，转写文本不作为视频素材。

| 频道 | 视频发布清单 | 转写文档目录 |
|---|---|---|
| 小岛大浪吹 | [CSV](../input/xiaodaodalang.csv) | [文档与进度](https://github.com/Business-Unit-for-Video/xiaodaodalang-video2text/blob/main/docs/video-index.md) |
| Better Leaf 好葉 | [CSV](../input/betterleaf.csv) | [文档与进度](https://github.com/Business-Unit-for-Video/betterleaf-video2text/blob/main/docs/video-index.md) |

GitHub Actions 中手动运行 **同步 YouTube 频道发布清单** 可刷新。每天也会自动同步一次；同步不会投稿。
已存在的视频顺序保持不变，新发现的视频追加到末尾。暂时不再公开的视频会从候选清单移除，历史发布状态继续保留。
文档链接仅在转写文件实际生成后填写。尚未转写的视频同样可以按原视频发布流程处理。

发布方式见 [频道发布说明](youtube-channel-publishing.md)。
